# My first programming  project

I am passionate about gaming so coding a game was a clear thing I wanted to do.
The game window is small, but all the features are there to play a 9x9 grid minesweeper with 10 bombs.

# To run the game (Windows)

- Activate the virtual environment with "*source  .venv/bin/activate*"
- Run the game with "*python3 main.py*"
